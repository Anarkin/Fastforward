# CONTRIBUTING

- Use Conventional Commits, following this format exactly:

  ```
  <type>[(<scope>)][!]: <description>

  [- <bullet>]
  [- <bullet>]
  ```

  - Allowed types: `fix`, `feat`, `refactor`, `test`, `perf`, `docs`, `style`, `chore`, `ci`, `build`, `revert`
  - Scope is optional
  - Breaking changes are marked by `!`
  - The first line is not longer than 72 characters
  - The body is optional: none, or one or more bullets, each on one line, unwrapped
  - There are no footers or trailers of any kind

- No code comments
